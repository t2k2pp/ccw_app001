# 要求定義書

## プロジェクト概要

ローカルLLMとローカル画像生成AIを活用した、インテリジェントなスライド作成アプリケーション。
Gamma、Beautiful.ai、Canva、Google Slidesなどの優れたスライド作成サービスの機能を参考にしつつ、
完全にローカル環境で動作する、プライバシーとカスタマイズ性を重視したソリューションを提供します。

## ビジネス目標

### 主要目標
1. **プライバシー保護**: 機密情報を扱う企業・個人が安心して使える
2. **生産性向上**: AIの力で、従来の1/5の時間でプレゼンテーション作成を実現
3. **品質向上**: デザインの知識がなくても、プロフェッショナルな見た目のスライドを作成
4. **柔軟性**: 完全自動生成から手動編集まで、ユーザーのスタイルに合わせた作業が可能

### ビジネス要求
- **オフライン動作**: インターネット接続不要（AI機能を除く）
- **コスト削減**: 有料サービスへの月額課金が不要
- **拡張性**: プラグインでコミュニティが機能を追加できる
- **多用途対応**: ビジネスプレゼンからデジタルサイネージまで

## ステークホルダー

### 主要ユーザー
1. **ビジネスユーザー**: 企画書、提案書、報告書の作成
2. **教育関係者**: 授業資料、研修資料の作成
3. **マーケター**: 商品紹介、キャンペーン資料の作成
4. **店舗運営者**: デジタルサイネージコンテンツの作成
5. **個人クリエイター**: ポートフォリオ、作品紹介の作成

### 対象外
- 高度なアニメーション制作（After Effects レベル）
- 動画編集（専門的な動画編集ソフトの代替ではない）
- 大規模コラボレーション（Google Docsのようなリアルタイム編集は将来機能）

## ビジョン

### 短期ビジョン（1年以内）
- **プライバシー第一**: すべての処理をローカルで完結し、機密情報が外部に漏れる心配がない
- **AI支援と手動編集のハイブリッド**: 完全自動生成から細かな手動調整まで、柔軟な作業スタイルに対応
- **プロフェッショナルな品質**: テンプレートとAIの組み合わせで、デザインの知識がなくても美しいスライドを作成

### 長期ビジョン（2-3年）
- **エコシステム構築**: コミュニティによるテンプレート、テーマ、プラグインのマーケットプレイス
- **多言語対応**: 日本語・英語以外の主要言語に対応
- **クロスプラットフォーム**: Web、Desktop（Windows/Mac/Linux）、モバイル（将来）

## 成功基準

### 定量的指標
- **ユーザー数**: 1年で1万ユーザー獲得
- **作成時間短縮**: 従来比80%削減
- **ユーザー満足度**: NPS（ネットプロモータースコア）50以上
- **継続利用率**: 月次アクティブ率60%以上

### 定性的指標
- ユーザーが「プライバシーが守られている」と感じる
- ユーザーが「AIのおかげで楽になった」と感じる
- ユーザーが「プロっぽい資料が作れた」と感じる

## 制約条件

### 技術的制約
- ローカルLLMが必要（Ollama、LM Studio等のインストールが前提）
- 画像生成にはGPU推奨（CPU でも可能だが遅い）
- ブラウザまたはデスクトップアプリとして動作

### リソース制約
- 初期は少人数開発（1-3名）
- オープンソースプロジェクトとして運営
- 外部サービス費用は最小限（ローカル動作を優先）

### 時間的制約
- MVP（最小機能製品）は3-6ヶ月で完成
- Phase 2（AI画像統合）は6-9ヶ月
- Phase 3（プレゼンテーション機能）は9-12ヶ月

## リスクと対策

### リスク
1. **LLMの性能不足**: ローカルLLMの品質が低く、生成結果が使えない
   - **対策**: 複数モデル対応、ユーザーが調整可能なパラメータ提供

2. **パフォーマンス問題**: 大量スライドで動作が重い
   - **対策**: 仮想化、遅延読み込み、最適化

3. **競合サービス**: GammaやBeautiful.aiが機能強化
   - **対策**: プライバシーとローカル動作を差別化要因に

4. **ユーザーの学習コスト**: AIの使い方が難しい
   - **対策**: チュートリアル、テンプレート、サンプルプロジェクト

## 参考サービス分析

### Gamma (https://gamma.app/)
- **強み**: AI駆動、カード型UI、簡単操作
- **弱み**: クラウド依存、プライバシー懸念、有料プラン必須（高度機能）
- **学ぶ点**: AI生成のUX、テンプレート自動適用

### Beautiful.ai (https://www.beautiful.ai/)
- **強み**: スマートテンプレート、自動デザイン調整
- **弱み**: クラウド依存、高額（月額$12〜）
- **学ぶ点**: 自動レイアウト調整、デザインルール

### Canva (https://www.canva.com/)
- **強み**: 豊富なテンプレート、素材ライブラリ
- **弱み**: プレゼン特化ではない、有料素材多数
- **学ぶ点**: ドラッグ&ドロップUI、素材管理

### Google Slides (https://slides.google.com/)
- **強み**: 無料、コラボレーション、シンプル
- **弱み**: AI機能なし、デザイン自由度低い
- **学ぶ点**: シンプルさ、使いやすさ
