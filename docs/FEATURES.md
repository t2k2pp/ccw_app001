## ユーザーストーリー

### 1. AI支援による完全自動生成

```
As a ユーザー
I want to トピックを入力するだけでスライドを自動生成したい
So that 短時間でプレゼンテーションを作成できる
```

**受入基準**:
- トピックとスライド枚数を入力できる
- 10枚程度のスライドが5分以内に生成される
- 各スライドに適切なレイアウトが自動適用される
- 必要に応じて画像が自動生成される

### 2. 手動編集とAI支援のハイブリッド

```
As a ユーザー
I want to 既存のスライドを編集し、必要な部分だけAIに手伝ってもらいたい
So that 自分のアイデアを保ちながら効率的に作業できる
```

**受入基準**:
- 手動でスライドを追加・削除・並び替えできる
- 個別の要素（テキスト、画像）をAIで生成できる
- AIの提案を承認・却下・編集できる

### 3. テンプレートによる一貫性

```
As a ユーザー
I want to 統一されたデザインのスライドを作成したい
So that プロフェッショナルな見た目のプレゼンテーションになる
```

**受入基準**:
- 複数のプリセットテンプレートから選択できる
- テンプレートを途中で変更できる
- 全スライドに一貫したデザインが適用される

### 4. 柔軟なエクスポート

```
As a ユーザー
I want to 作成したスライドを様々な形式でエクスポートしたい
So that 異なる環境やツールで使用できる
```

**受入基準**:
- PDFで高品質に出力できる
- PowerPoint形式で出力できる（編集可能）
- 各スライドを画像として保存できる

### 5. デジタルサイネージとしての活用

```
As a ユーザー
I want to 作成したスライドをデジタルサイネージとして自動再生したい
So that 店舗や展示会で無人で情報を表示できる
```

**受入基準**:
- スライドを指定時間で自動切り替えできる
- ループ再生ができる
- トランジション効果を設定できる
- フルスクリーンで表示できる

### 6. 音声付きプレゼンテーション

```
As a ユーザー
I want to 各スライドにトークスクリプトを設定し、音声で自動再生したい
So that プレゼンテーションを録画したり、無人デモに使用できる
```

**受入基準**:
- 各スライドにトークスクリプトを入力できる
- AIがスライド内容からスクリプトを自動生成できる
- 音声合成でスクリプトを読み上げられる
- 音声の速度や音程を調整できる
- スライド表示と音声を同期できる

### 7. アイコンとSVGの活用

```
As a ユーザー
I want to プリセットのアイコンやSVGを簡単に挿入したい
So that 視覚的に分かりやすいスライドを素早く作成できる
```

**受入基準**:
- 豊富なアイコンライブラリから選択できる
- アイコンを検索できる
- SVGファイルをインポートできる
- AIがスライド生成時に適切なアイコンを選択できる
- アイコンの色やサイズを変更できる

## 機能詳細

### 1. プロジェクト管理

#### 1.1 プロジェクト作成
- **新規プロジェクト**:
  - プロジェクト名の設定
  - テンプレートの選択（オプション）
  - テーマの選択（オプション）
  - スライドサイズの選択（16:9, 4:3, カスタム）

- **テンプレートからの作成**:
  - プリセットテンプレートの一覧表示
  - プレビュー表示
  - テンプレート選択で即座に開始

- **AI支援作成**:
  - トピック入力
  - 対象者（ビジネス、学生、一般など）
  - スライド枚数の指定
  - トーン（フォーマル、カジュアルなど）
  - AI自動生成

#### 1.2 プロジェクト保存・読み込み
- **自動保存**:
  - 30秒ごとの自動保存
  - 変更があった場合のみ保存
  - 保存ステータスの表示

- **手動保存**:
  - Ctrl+S（Cmd+S）で保存
  - 「名前を付けて保存」機能

- **プロジェクト一覧**:
  - サムネイル付き一覧
  - 最終更新日時表示
  - 検索・フィルター機能

#### 1.3 プロジェクト設定
- **基本設定**:
  - プロジェクト名
  - 作成者
  - 説明

- **スライド設定**:
  - デフォルトサイズ
  - 背景色
  - フォント設定

### 4. テンプレートシステム

#### 4.1 プリセットテンプレート（MVP）
以下のレイアウトを最低10種類提供：

1. **タイトルスライド**
   - 大きなタイトル
   - サブタイトル
   - オプション: 背景画像、ロゴ

2. **セクションタイトル**
   - 中央揃えの大きなタイトル
   - オプション: 装飾要素

3. **箇条書き（1カラム）**
   - タイトル
   - 3-7個の箇条書き
   - オプション: アイコン

4. **箇条書き（2カラム）**
   - タイトル
   - 左右に箇条書き
   - 比較に適した構成

5. **画像中心**
   - 大きな画像
   - キャプション
   - オプション: タイトル

6. **画像+テキスト（左右分割）**
   - 左: 画像 / 右: テキスト（または逆）
   - バランスの良いレイアウト

7. **画像+箇条書き**
   - 上: 画像
   - 下: 箇条書き

8. **引用・キーメッセージ**
   - 大きな引用文
   - 引用元
   - 装飾的な背景

9. **3カラム**
   - タイトル
   - 3つの列（アイコン+テキスト）
   - 特徴やメリットの提示に最適

10. **まとめスライド**
    - タイトル
    - 主要ポイントのまとめ
    - CTA（コールトゥアクション）

#### 4.2 自動レイアウト選択
- **選択基準**:
  - テキスト量
  - 画像の有無と枚数
  - 箇条書きの項目数
  - スライドの位置（冒頭、中盤、終盤）

- **選択ロジック**:
```typescript
function selectLayout(content: SlideContent, position: number, total: number): LayoutTemplate {
  // 最初のスライド
  if (position === 0) return TitleSlideLayout;

  // 最後のスライド
  if (position === total - 1) return SummarySlideLayout;

  // 画像メイン
  if (content.images.length > 0 && content.text.length < 100) {
    return ImageCentricLayout;
  }

  // 箇条書き
  if (content.bulletPoints && content.bulletPoints.length > 0) {
    if (content.bulletPoints.length > 6) {
      return TwoColumnBulletLayout;
    }
    return BulletPointLayout;
  }

  // デフォルト
  return ContentLayout;
}
```

#### 4.3 カスタムテンプレート（Phase 3）

### 5. テーマシステム

#### 5.1 プリセットテーマ（MVP）
以下のテーマを提供：

1. **Professional（プロフェッショナル）**
   - カラー: ネイビー、グレー、ホワイト
   - フォント: Roboto / Noto Sans JP
   - スタイル: シンプル、ミニマル

2. **Modern（モダン）**
   - カラー: ブラック、ホワイト、ビビッドなアクセント
   - フォント: Montserrat / Noto Sans JP
   - スタイル: 大胆、コントラスト

3. **Warm（ウォーム）**
   - カラー: ベージュ、ブラウン、オレンジ
   - フォント: Lora / Noto Serif JP
   - スタイル: 温かみ、親しみやすい

4. **Cool（クール）**
   - カラー: ブルー、シアン、ホワイト
   - フォント: Open Sans / Noto Sans JP
   - スタイル: 清涼感、信頼感

5. **Vibrant（ヴァイブラント）**
   - カラー: 鮮やかな多色
   - フォント: Poppins / Noto Sans JP
   - スタイル: エネルギッシュ、創造的

6. **Minimal（ミニマル）**
   - カラー: ホワイト、グレー、ブラック
   - フォント: Inter / Noto Sans JP
   - スタイル: 極限までシンプル
